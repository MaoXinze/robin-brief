# 05 · 运行与部署指南

## 5.1 环境准备

要求：Python 3.12+（用 uv 管理最省心）、可选 Docker、可选飞书机器人。

```bash
# 克隆/进入项目后
uv venv --python 3.12                 # 创建 .venv（uv 自动下载 Python 3.12）
uv pip install -r requirements-dev.txt
uv pip install -e . --no-deps         # 安装 robin 命令行
```

没有 uv 的话：`pip install uv` 或用 `python -m venv .venv` + pip 亦可。

## 5.2 配置 LLM API Key

```bash
robin init        # 复制 .env.example 为 .env
```

编辑 `.env`：

```ini
ROBIN_LLM_API_KEY=sk-xxxxxxxx        # DeepSeek: https://platform.deepseek.com
ROBIN_LLM_BASE_URL=https://api.deepseek.com
ROBIN_LLM_MODEL=deepseek-chat
```

**换供应商**：任何 OpenAI 兼容端点都行，改两个变量即可，例如：

```ini
ROBIN_LLM_BASE_URL=https://api.moonshot.cn/v1   ROBIN_LLM_MODEL=kimi-k2-0905-preview
ROBIN_LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4  ROBIN_LLM_MODEL=glm-4.6
```

## 5.3 常用命令

| 命令 | 作用 |
|---|---|
| `robin demo` | **离线演示**：内置样例数据 + 规则式伪智能，无需 Key/网络，一键生成示例早报 |
| `robin run` | 真实运行：抓取所有启用源 + LLM 生成今日早报 |
| `robin run --date 2026-09-05` | 生成指定日期的早报 |
| `robin run --no-push` | 本次不推送飞书 |
| `robin run -v` | 详细日志（看每个源的抓取与去重细节） |
| `robin archive` | 查看历史日报归档 |
| `robin schedule --at 08:30` | 常驻进程，每天 08:30（东八区）自动出版 |
| `robin init` | 初始化 .env |

产物位置：`output/<日期>/brief.html`（主产物）、`brief.md`、`run_report.json`。

## 5.4 数据源配置（config/sources.yaml）

```yaml
sources:
  - id: jiqizhixin            # 唯一 ID
    name: 机器之心             # 日报上显示的来源名
    type: rss                # rss | hackernews | arxiv | github_trending
    url: https://www.jiqizhixin.com/rss
    weight: 4                # 来源权重（去重优先级、评分参考）
    lang: zh
    enabled: true            # false 可临时停用
```

各类型专有参数：

- `hackernews`：`query`（关键词）、`min_points`（热度阈值，宽松重采时自动减半）
- `arxiv`：`categories`（如 cs.AI / cs.CL）、`max_results`
- `github_trending`：`language`、`ai_keywords`（AI 相关性过滤）、建议 `headline_eligible: false`（仓库条目只进快讯）

**新增一个源**：若是 RSS 直接加一行配置；若是新站点类型，在 `sources/` 加一个 `BaseSource` 子类并在注册表登记 —— 适配器接口只有 `fetch()` 一个方法。

## 5.5 飞书机器人推送

1. 飞书群里：设置 → 群机器人 → 添加自定义机器人（自定义关键词建议填「早报」）
2. 取 Webhook URL 填入 `.env`：
   ```ini
   ROBIN_FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/xxxx
   ROBIN_FEISHU_SECRET=            # 若开启了签名校验则填写
   ```
3. `robin run` 成功后自动推送交互卡片（头条+点评+快讯，含原文链接）

推送是"尽力而为"：Webhook 未配置或推送失败都不影响早报生成，结果记录在 run_report。

## 5.6 定时运行的三种方式

**方式一：本机常驻（最简单）**

```bash
robin schedule --at 08:30     # APScheduler 每日 cron，Ctrl+C 退出
```

**方式二：操作系统计划任务**

```bash
# Windows 计划任务 / Linux crontab 示例（每天 08:30）
30 8 * * * cd /path/to/AI-Morning-Brief && .venv/Scripts/robin run >> robin.log 2>&1
```

**方式三：Docker**

```bash
docker build -t robin-brief .
# 演示
docker run --rm -v "${PWD}/output:/app/output" robin-brief robin demo
# 真实运行（.env 提供 Key）
docker run --rm --env-file .env -v "${PWD}/output:/app/output" -v "${PWD}/data:/app/data" robin-brief robin run
```

容器化定时建议在宿主机用 cron/K8s CronJob 触发一次性 `robin run`（容器即抛即弃），而不是容器内常驻 APScheduler。

## 5.8 FAQ

**Q: 没有 API Key 能体验吗？**
`robin demo` 全离线出报；`robin run --mock` 用真实数据 + 规则式伪智能（需要网络但不需要 Key）。

**Q: 某个源一直失败？**
看 run_report 的 source_errors；用浏览器确认源地址是否可访问/被墙；或临时 `enabled: false`。单源失败从不阻塞整体。

**Q: 摘要质量差 / 分类不准？**
改 `src/robin/prompts/*.txt`（提示词独立成文件就是为了调优）。中文日报建议选中文能力强的模型。

**Q: 当天重复运行会怎样？**
同一日期重复出报是安全的：日报按主键覆盖、文章按 (run_date, id) 覆盖；跨天去重只对比"更早"的日期，不会误杀当天重跑。

**Q: 首次运行为什么没有"昨日回顾"？**
昨日回顾取自上一个已归档日报的头条，跑几天后自然出现。

**Q: Windows 控制台中文乱码？**
用 Windows Terminal；或 `chcp 65001` 切换 UTF-8 后再运行。
